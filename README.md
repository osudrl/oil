# OIL: An Object Interaction Layer for Humanoid Whole-Body Control

**Best Paper Nominee · UR-RAD AAAI Symposium 2026**

Pranay Dugar, [Mohitvishnu S. Gadde](https://mohitgadde.github.io/), [Rajesh Mangannavar](https://rajeshdm.github.io/), [Aayam Kumar Shrestha](https://idigitopia.github.io/), [Alan Fern](https://engineering.oregonstate.edu/people/alan-fern)

[Dynamic Robotics and AI Lab (DRAIL)](https://mime.engineering.oregonstate.edu/research/drl/), Oregon State University

[Project Page](https://osudrl.github.io/oil/) · [Paper (PDF)](https://arxiv.org/pdf/2610.14033) · [arXiv](https://arxiv.org/abs/2610.14033)

OIL adds object motion and contact intent to humanoid whole-body control. A single learned layer enables sliding, pick-and-place, carrying, and pushing through a shared directive interface, while reusing a frozen controller's balance and locomotion.
