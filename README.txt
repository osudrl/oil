OIL Project Website

Hosting
-------
Extract this ZIP and upload its contents to any static web host (GitHub Pages,
Netlify, Cloudflare Pages, or an ordinary web server). index.html must be at
the root of the published directory. No build step, installation, API key,
or server-side runtime is required.

Keep the assets directory beside index.html. The embedded demonstration
video and research images are included. Google Fonts loads over the internet;
system fonts are used as a fallback. Paper and institutional links point to
their public websites.

To preview locally, run:
  python3 -m http.server 8000
Then open http://localhost:8000 in a browser.

Files
-----
index.html   Page content
style.css    Page styling
script.js    Copy-citation interaction
assets/      Images, demonstration video, and favicon
